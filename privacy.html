Privacy policy

Effective date: 23 October 2026.

Data accessed and purpose

This personal automation accesses Google Drive file metadata and, when needed for authorized review or repair, selected file contents. It uses the Drive readonly scope for inventory and the full Drive scope for management. Access supports file organization, handoff review, replica reconciliation and evidence of completed repairs.

Processing and storage

OAuth client configuration and access/refresh tokens are stored in access-restricted local credential folders outside the knowledge vault, source repository and public website. Inventory snapshots, change cursors and operation receipts are saved locally for continuity, verification and recovery.

The owner operates the automation with local tools and an AI assistant. Selected metadata or file content may be processed by the assistant provider when the owner uses that assistant for review or repair, under the owner's provider settings and applicable service terms. This website does not accept uploaded Drive files or collect visitor data through forms or analytics.

Use and disclosure

Google user data is used for the described personal automation. The application does not sell that data, use it for advertising, or publish it through this website. Public sharing and other external disclosure require the owner's applicable instructions. The application's use of Google API data follows the Google API Services User Data Policy, including its Limited Use requirements.

Retention and revocation

Local evidence is retained as needed for continuity, diagnosis and recovery. The owner controls those local files and credential stores and may delete them. Access can be revoked in Google Account connections. Revoking access stops subsequent authorized requests but does not remove existing local copies; the owner must remove those separately.
