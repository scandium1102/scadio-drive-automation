Scadio Second Brain Drive Scan

A personal Google Drive automation used by its owner to inspect file placement, reconcile a local knowledge library and diagnose and repair authorized errors.

What it does

The daily inventory reads file identifiers, parent folders, names, versions and available checksums. Changes API cursors support incremental checks, with periodic full reconciliation. The management connection supports creating, uploading, updating, moving, copying, downloading and deleting Drive resources according to the account's permissions.

The workflow records observations, performs eligible repairs using authoritative ownership and destination evidence, and verifies the resulting state. Inventory coverage is separate from content, identity and repair acceptance.

Access and control

The inventory and management connections use separate local credential stores. The account owner can revoke access through Google Account connections. This is a personal automation, with no public sign-up or hosted document intake.

Support: use the owner/support email shown on the Google consent screen.
